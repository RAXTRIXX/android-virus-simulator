ANDROID VIRUS SIMULATOR — SAFE EDUCATIONAL WEBSITE

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html dengan browser Android/PC.
3. Tidak perlu instalasi, server, login, atau koneksi internet.

Keamanan:
- Demo berjalan lokal di browser.
- Tidak meminta izin Android.
- Tidak membaca, mengubah, mengenkripsi, menghapus, atau mengunci file.
- Tidak mengirim data dan tidak membuat koneksi jaringan.
- Semua file, ancaman, dan log adalah data contoh/simulasi.

Untuk edukasi keamanan siber saja.
